Meu Site Simples

seguencia Git


Criar branch

-> git checkout -b + nome da branch

Resolva o ticket.

Colocar os arquivos no stage

-> git add + nome do arquivo ou git add .

commit os arquivos no stage

-> git commit -m "msg do commit"

Mandar a sua branch para o github

-> git push -u origin + nomde da branch

Atualizar o repo


-> git pull
